# 240p Test Suite DB for MiSTer

240p Test Suite DB for MiSter has
[240p Test Suite](https://artemiourbina.itch.io/240p-test-suite) for the following cores:

* Gameboy
* GBA
* Master System
* MegaCD
* Megadrive
* MiSTer
* N64
* Neo Geo
* Neo Geo CD
* NES
* Playstation
* Sega 32X
* Saturn
* SNES
* TurboGrafx16
* TurboGrafx16 CD

## Installation

Add the following to `downloader.ini`

```ini
[ajgowans/240p]
db_url = https://raw.githubusercontent.com/ajgowans/240p/db/db.json.zip
```

Then run `update_all`
